🛡️ PhishGuard — Phishing URL Detector

A 2nd-year B.Tech AI/ML project by Vikranth Reddy. A logistic regression model trained on 1,000 URLs (500 genuine, 500 phishing) reads 10 clues from any link — suspicious words, IP-address hosts, extra subdomains, hyphens, missing HTTPS and more — and returns a phishing-risk score. 5-fold CV: accuracy = 99.9%, AUC = 1.000 vs a 50.0% coin-flip baseline. (Trained on synthetic URLs, so treat the score as a classroom demo, not a security verdict.)

How it works: the URL is broken into 10 numbers (length, dots, hyphens, digits, ‘@’, IP host, subdomain count, suspicious-word count, HTTPS, path length). Each is standardised, multiplied by the model's learned weight, and passed through a sigmoid to give a phishing probability. The same weights run in this page and in the Python training script (train.py), so the browser result matches the trained model exactly.

Try it: https://secure-login-verify.com/login/verify → phishing, about 99.9%. http://185.23.44.19/login/verify → phishing, about 99.6% (an IP address instead of a domain name is a classic red flag). https://www.google.com/search?q=laptop → phishing, about 0.1%.
